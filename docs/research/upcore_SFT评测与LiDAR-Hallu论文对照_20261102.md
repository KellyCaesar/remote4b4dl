# upcore SFT 完整评测与 LiDAR-Hallu 论文对照

**结论：**当前 SFT 能输出结构化几何推理，并对场景特征变化有一定敏感性；但原六任务中的存在性和二元问答退化，几何数值证据链仍有明显缺口。论文与本项目的问题、输入和解码协议不同，论文数字用于识别问题和设计对照，不能直接计算模型提升幅度。

两模型使用同一自由协议、30,145 条问题及相同推理数值设置。准确率以百分比呈现，时间定位和语言任务使用原始 0–1 指标。

存在性与二元问答的下降超过用户在后续方案中选定的 2 个百分点容忍范围；该阈值是后续方案的决策标准，不是本次评测预注册的统计显著性结论。时间定位有所上升，不能据此表述为六任务全面改善。SFT 同时改变 projector、时序适配器和 LoRA，现有对照不能将变化归因于单一组件。

以场景为单位、2,000 次 bootstrap 的配对准确率差区间分别为：重复首帧 `[-4.07, -0.36]`、乱序 `[+0.13, +1.37]`、跨场景替换 `[-13.70, -8.29]` 个百分点。这些区间以当前开发集和每场景固定的一次排列为条件，不代替独立数据和多种子复验。置零导致大量结构无效，不能把准确率下降直接解释为已证明可靠使用 LiDAR。

按 request ID 对已完成的逐条评分只读复算，以原始标签为基准，“错改对 / 对改错”分别为：重复首帧 `623 / 919`，乱序 `225 / 136`，跨场景替换 `923 / 2,432`。干预可能使输入与原标签不再对应，这些只是相对于原标签的配对记账，不表示被扰动输入上的回答真实正确或错误。

乱序时帧特征与原时间/位姿不再对应；首帧重复时位姿仍在变化；跨场景特征来自同一 split、相同帧数的另一场景。三者的变化不能单独证明模型理解运动，也不能与论文的 TSCD 解码结果混为一谈。

## 四、几何测试与思维链

在独立 test 的 14,946 条原始输入上，结构有效率为 100%。完整证据链通过要求答案正确、步骤依赖与推导符合规则，计数精确，连续数值误差严格小于 1 米。

| 几何任务 | 题数 | 答案准确率 | 完整证据链通过率 |
| --- | ---: | ---: | ---: |
| 存在性 | 11,028 | 82.99% | 64.07% |
| 方位 | 2,122 | 51.74% | 5.56% |
| 距离 | 328 | 50.91% | 0.00% |
| 相对运动 | 1,468 | 70.16% | 15.74% |

存在性占 test 的 73.79%，总体通过率不能代表其他任务。距离的 328 条是 82 个语义事件各作四次选项轮换；完整链要求四个候选距离的观测均通过阈值，0% 不等于距离答案准确率为零。几何 test 尚无原始 B3 在同一结构化提示下的完整对照，不能据此宣称优于 B3。

开发集错误分类中，方位题有 933 条、运动题有 782 条、距离题有 170 条“答案正确但证据链未通过”。例如 request `00027d7e618d27ed126a914e` 的方位答案正确，但预测的 `x`、`y` 与标注框中心分别相差约 1.63 米和 5.16 米。生成的思维链是可核验输出，不单独证明模型内部的真实计算过程。

## 五、与 LiDAR-Hallu 论文的数据对照

论文为《激光雷达语言模型真的理解时空关系吗？》，预印本 `arXiv:2609.24452v1`。本文使用用户提供的译文 `D:/学习/mmb4dl-up/4DLLM Dis 仅译文.pdf`，SHA256 `79f34a4ca28b2d9e0876b7f263bf2d7af2250c1077f3d3ed4e339da63d197936`；具体数字来自第 3–7 页的表 II–VII。论文的 LiDAR-Hallu 包含 150 个 nuScenes 验证场景中的 10,000 题，五类任务各 2,000 题，包含 4,000 条二元题和 6,000 条四选一题。

两项结果不能直接相减：本项目几何 test 有 14,946 题、四类任务，按实际 `CAM_BACK_RIGHT` 输入支持筛选并要求结构化步骤；论文任务构成、标签筛选、模型、提示、解码和数值设置均不同。论文 B4DL 的 36.65% 总体准确率不能与本项目 SFT 的 76.59% 当作同口径模型比较。

### 横向运动与正例召回

论文表 V 中，B4DL 和 B4DL-Ego 对向左、向右运动的正例召回均为 0%。两边均以各端点自车坐标下 `Δy ≥ 1m` / `Δy ≤ −1m` 定义左右关系；下表的当前 SFT 结果由本项目 test 的请求谓词、标准答案和预测答案按 request ID 只读复算：

| 关系 | 论文 B4DL 正例召回 | 当前 SFT 正例召回 | 当前 SFT 假正例率 | 当前完整链通过 |
| --- | ---: | ---: | ---: | ---: |
| 向左 | 0/145，0% | 20/44，45.45% | 15/44，34.09% | 9/88，10.23% |
| 向右 | 0/157，0% | 95/156，60.90% | 20/156，12.82% | 33/312，10.58% |

当前模型在自己的题集上能对部分横向运动正例回答“Yes”，但这不是同题同模型对照；当前左右正例分别来自 14 和 20 个场景，不能据此认定优于论文模型。完整链结果也显示正确二元答案不等于数值证据充分。

### 选项偏差、相反答案配对与候选先验

- 论文表 III 的 B4DL 距离选择题准确率为 24.30%，与固定选择 A 的结果相同；论文报告距离和时间选择题存在强烈的固定选 A 行为。本项目的 328 条距离轮换中，预测 A/B/C/D 分别为 50/105/90/83 次，未出现该样本上的极端固定选 A，但 82 组中仅 39 组四次选择语义一致、26 组四次全部正确。
- 论文表 IV 的 B4DL 在 348 对相同提示、相反标签问题中同时答对 43 对（12.36%）。本项目 test 的同类严格配对为 3,151 对，其中 1,175 对同时答对（37.29%）。题集、配对组成、提示、模型及可见范围不同，不能将差值解释为模型改进幅度。
- 论文的时间候选跨度对照仅使用其他场景的标签统计，未使用事件描述或 LiDAR，达到 69.30% 的时间选择题准确率。该结果提示后续须保留候选内容、固定答案和训练集先验对照，避免将题目格式泄漏误当作时间理解。

### 时间乱序与 TSCD

论文 TSCD 在解码时同时使用原始与乱序分支的 logits；表 VII 中 B4DL 的净变化为 +0.03 至 +0.04 个百分点，三个对应 95% 区间均包含零。本项目干预是仅用乱序特征做单分支推理，未实现 TSCD，不能直接比较两者的增益。两者共同说明：应同时记录答案变化、错改对和对改错，而不是只报告总体净变化。
